
# DIGISMART

Website edukasi untuk meningkatkan literasi digital masyarakat.

## Deskripsi

DIGISMART merupakan platform pembelajaran digital
yang bertujuan meningkatkan pengetahuan pengguna
mengenai penggunaan teknologi secara cerdas,
aman, dan bertanggung jawab.

## Fitur

1. Login pengguna
2. Registrasi pengguna
3. Dashboard
4. Materi literasi digital
5. Edukasi anti-hoaks
6. Keamanan digital
7. Kuis interaktif
8. Sistem penilaian
9. Pencatatan perkembangan belajar

## Teknologi

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SessionStorage

## Cara Menjalankan

1. Buat folder DIGISMART.
2. Simpan semua file website di dalam folder tersebut.
3. Buka folder menggunakan Visual Studio Code.
4. Jalankan index.html menggunakan Live Server.
5. Pilih menu Daftar untuk membuat akun.
6. Masuk menggunakan akun yang telah dibuat.

## Catatan

Versi ini merupakan prototipe frontend.
Sistem autentikasi masih menggunakan penyimpanan
lokal browser dan belum cocok untuk penggunaan publik.

## Pengembang

DIGISMART - Cerdas dan Aman di Dunia Digital.
